## 一、背景：两个试点现场，同一批痛点

WorkBot 的能力在两个差异极大的现场被反复验证，也暴露出**跨行业高度同构的痛点**：

- **跨境物流现场**：华东物流代理的对账单据需要逐票验真，假单、查无此单、重复申报频发（Day 17 A2A 验真协议由此而生）；
- **医疗与保险理赔初审现场**：5 万员工的理赔发票初审面临同样的问题——外部单据真假难辨、老员工经验无法复制、初审规则被绕行。

**关键洞察：这两类现场没有一个是「行业问题」，全部是「产品能力缺口」。** 现在把它们沉淀为通用产品提案，而不是每次现场重新救火。

## 二、共性痛点（四条，跨现场重复出现 ≥ 2 次）

| # | 痛点 | 物流现场表现 | 医疗理赔现场表现 |
|---|---|---|---|
| 1 | 外部单据验真无统一能力 | 运单号 EWB 验真（假单 / 查无此单 / 超时） | 理赔发票真伪核验（发票抬头 / 诊疗项目比对） |
| 2 | 老员工隐性知识不可复制 | 「这家货代 6 月改名了，税号没变」 | 「这家诊所的发票模板 3 月更新过」 |
| 3 | 拆单 / 重复申报靠人眼 | 同一运单拆成 3 票报销 | 同一诊疗拆成多张发票分次理赔 |
| 4 | 用户绕行 = 信任赤字 | 代理继续用 Excel 对账 | 理赔专员继续手工台账 |

## 三、提案（P1 ~ P4，按优先级）

### P1 · 单据验真中间层（Document Verification Layer）

把 Day 17 的外部 A2A 验真协议组件化为核心产品能力：

- 统一验真接口：超时熔断（2500ms）+ 连续失败熔断冷却 + 假单 / 查无此单 / 超时 / 熔断**一律转人工**，绝不硬凑「验真通过」放行；
- 验真调用全链路留痕（独立 Span，角色 external_a2a），可回放；
- 各行业只写「适配器」（物流运单 / 医疗发票 / 银行回单），协议层零改动。

### P2 · 人工分歧复盘回流机制（Divergence Feedback Loop）

把 Day 38 影子对拍的分歧处置做成产品常驻能力：

- 每一次人机分歧自动生成「分歧卡」，强制三分类裁决：人错机对 / 机错人对 / 双错；
- 机错人对类分歧一键回流为**知识卡**（如供应商别名索引）进检索池，下一轮判定自动生效；
- 人错机对类分歧自动汇入复训清单；
- 分歧台账只增不改，可审计。

### P3 · 确定性算术守卫组件化（Deterministic Arithmetic Guard）

把「不靠模型、纯代码算」的守卫做成统一组件，供所有单据流复用：

- Σ（数量 × 单价）与申报总额的算术校验；
- 同主体同日多笔的拆单合并口径检测（合并后触发大额人工审批红线）；
- 汇率折算与重复申报（同发票号 / 同运单号）检测；
- 全部确定性规则，零概率成分——红线判定**物理上不依赖模型发挥**。

### P4 · 逃逸率埋点进核心产品（Bypass Telemetry）

把「绕行回 Excel」从 Crisis 手工统计升级为产品一级埋点：

- 通道级埋点实测逃逸率（不是问卷、不是拍脑袋）；
- 逃逸率上升自动触发 1v1 访谈工单，而不是考核通报；
- 看板口径与四硬指标一致（平均审单周期 / 返工率 / 逃逸率 / 拦截止损额），**禁止虚荣指标进老板看板**。

## 四、Non-Goals（本期明确不做）

1. 不做全自动理赔放款 / 自动打款——放行永远归人（红线，无例外）；
2. 不对接任何行业老 ERP 原生接口——只读快照 / 沙盒仿真；
3. 不做自由对话机器人——只做草稿 + 确认流；
4. 不做绕过审批的加急通道；
5. P1 验真协议不承诺各行业外部系统 100% 可用——不可用一律转人工，宁可慢不可错。

## 五、验收标准

| 提案 | 验收口径 |
|---|---|
| P1 | 物流运单 + 医疗发票双适配器通过假单 / 查无此单 / 超时 / 熔断四类演习；全部转人工，零硬凑放行 |
| P2 | 三类分歧裁决全覆盖；知识卡回流后对拍一致率提升可复现（≥ 一轮 20 单对拍验证） |
| P3 | 拆单合并口径 / 算术差异 / 重复申报三类样本 100% 拦截（确定性，不抽样） |
| P4 | 逃逸率埋点与通道真实日志比对一致；老板看板无任何虚荣指标 |
| 总门禁 | 全部改动重考 `.fde/05-eval-spec-20.md` 20 题，20/20 合格才放行 |

## 六、回滚方案

- P1：适配器按行业开关切换，关闭即回退到纯人工验真，验真记录保留可审计；
- P2：知识卡支持单张下线（记忆与知识可遗忘原则），下线后检索池即时生效；
- P3：守卫组件按单据类型开关，关闭后回归原有人工校验路径；
- P4：埋点为只读观测，关闭不影响任何业务流。
